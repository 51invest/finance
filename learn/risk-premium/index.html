风险溢价

风险溢价是风险资产预期回报高于无风险利率的部分；它补偿不可分散的风险，而不是所有波动。

读完这一篇，你能把“利差”“风险溢价”“已实现超额收益”分开，并用 CAPM 算出一个要求回报，而不是把高收益直接当成高溢价。

定义

风险溢价（risk premium）是风险资产预期回报高于无风险利率的部分，是对承担风险的补偿[1][3]。市场风险溢价（market risk premium）是市场组合预期回报减无风险利率，资产风险溢价则按资产的系统性风险调整[3]。

直觉

假设在同一币种下，一年期国债收益率为 4.0%、同期限公司债为 6.5%；本文以同期限国债充当无风险基准，教材则常用三个月期美国国债利率作无风险参照[1]。2.5 个百分点的利差中，一部分补偿违约和流动性风险[2]，剩余部分才更接近预期风险溢价。股票的风险溢价补偿无法通过分散化消除的市场风险，而不是个别公司的特有风险。

正式表达

资产风险溢价：

RP_i = E[R_i] - R_f

市场风险溢价：

MRP = E[R_m] - R_f

资本资产定价模型（capital asset pricing model, CAPM）：

E[R_i] = R_f + β_i × MRP

其中 E[R_i] 是预期回报，R_f 是无风险利率，E[R_m] 是市场组合预期回报，β_i = Cov(R_i, R_m) / Var(R_m) 衡量系统性风险：Cov、Var 分别是协方差与方差，其样本估计口径与单位见协方差与相关性主文（RES-010），而教材把 β 写成对市场回报回归的斜率，本式是同一斜率的记号写法[3]。报价收益率可粗略拆为无风险利率、信用溢价、流动性溢价和期限溢价[2]；这是分析框架，不是精确的会计恒等式。

适用条件

  • 风险溢价是预期值，不是已实现超额收益；事后可能为负。
  • 比较时统一币种、期限、税务、流动性和违约特征。
  • 无风险利率只表示违约风险极低，仍含通胀、期限与再投资风险；其期限应与现金流匹配。
  • 在 CAPM 的假设下，被补偿的只有系统性风险，可分散的特有风险不抬高要求回报[3]；这是模型结论，不是对任何市场的断言。
  • 报价利差包含预期违约损失与流动性补偿，教材也把利息征税与可赎回条款列为影响债券收益率的因素[2]（可赎回条款即一种嵌入期权），因此利差通常高于预期风险溢价。
  • 本文把市场风险溢价当作给定常数只为完成算例；实际应用中它会随经济状态与估计窗口变化，本篇不给出估计方法。这是本文的口径说明，不是来源结论。

例子与计算

以下数字均为教学假设；所有利率在同一币种、同一期限口径下给出，MRP、要求回报与风险溢价都是年化百分数（差额以百分点计）。设 R_f = 4.0%，E[R_m] = 9.0%，则 MRP = 9.0% - 4.0% = 5.0%。

  • β = 0.8：E[R_i] = 4.0% + 0.8 × 5.0% = 8.0%，资产风险溢价 4.0%。
  • β = 1.2：E[R_i] = 4.0% + 1.2 × 5.0% = 10.0%，资产风险溢价 6.0%。

若同期限公司债收益率为 6.5%，与 4.0% 国债的利差为 2.5 个百分点；若预期违约损失为 1.0 个百分点，剩余 1.5 个百分点才更接近预期超额回报（仍未扣除流动性和税收）。

常见误解

  • 风险溢价就是历史超额收益。 不是。它是事前预期；历史结果受运气和估值变化影响。
  • 高收益债的利差全是风险溢价。 不是。利差还包含预期违约损失、流动性、税收和条款。
  • 波动率越高，溢价越高。 不一定。模型定价的是系统性风险，可分散的特有风险不因此获得补偿；分散化与特有风险的口径见分散化与共同风险主文（INV-017）。
  • 无风险利率真的没有风险。 不是。它通常只指违约风险极低，仍有通胀、期限与再投资风险。

知识点精读

无套利

定义：无套利是相同或等价现金流不应有不同价格，否则可零成本锁定无风险利润。

机制：套利者买卖高估和低估资产使价格收敛；交易成本、融资约束和卖空限制会阻止完全套利。

例子：例如同一股票在不同交易所价差大于交易成本，套利者买入低价、卖出高价直至价差收窄。

边界：无套利是定价约束而非价格预测；流动性枯竭、对手方风险和制度限制会让偏离持续，模型也需说明复制条件。

一价定律

定义：一价定律指同一商品在竞争市场、无运输和交易壁垒时应有同一价格，否则套利会消除差异。

机制：跨市场价差反映运输、关税、汇率、品质和交易成本；可贸易品与不可贸易品的收敛程度不同。

例子：例如同规格黄金在伦敦和纽约的美元价差通常很小，若扩大则套利资金会搬运或对冲。

边界：一价定律不是所有商品都成立；住房、服务和管制商品不可搬运，品牌、税和本地供需会维持价差。

风险溢价

定义：风险溢价是投资者持有风险资产而非无风险资产要求的额外预期收益，补偿不确定性。

机制：溢价由风险大小、相关性、流动性、杠杆和投资者风险偏好决定；股权、信用和期限溢价各有来源。

例子：例如股票长期预期收益高于国债，部分补偿盈利不确定和回撤风险。

边界：风险溢价不是保证收益；预期可能落空，历史溢价受样本和估值影响，低波动也可能伴随高估值和低未来回报。

资产定价与市场效率基础

定义：资产定价研究风险与预期收益的关系，市场效率研究价格吸收信息的程度。

机制：CAPM、多因子和现金流贴现给出不同定价框架；弱式、半强式和强式效率对应不同信息集。

例子：例如盈利公告后价格迅速调整，说明公开信息被较快吸收；若内幕交易持续获利，则强式效率不成立。

边界：市场效率不等于价格永远正确；噪声、套利限制、行为偏差和制度摩擦会造成错价，定价模型也可能遗漏风险因子。

数据与制度核对：风险溢价

把“风险溢价”放进真实数据之前，先核对四件事。第一是统计单位：来源报的是水平值、增长率、指数还是占比，分母是总产值、人口、劳动力还是金融资产；同一句话换掉分母就会得到不同结论。第二是时间口径：名义值与实际值、季调与非季调、财年与日历年不能直接拼接，涉及“市场风险溢价”时尤其要写明基期和折算方法。

第三是制度边界。信用利差在来源国的法律、监管和会计规则下成立，换到另一套制度里，定义可能不覆盖同一批主体；跨境比较要先检查样本是否被同一规则约束。第四是反向核对：用另一个独立来源重算关键比例，至少让数量级、方向和单位对得上，再讨论因果。

边界条件与迁移练习：风险溢价

学习“风险溢价”最容易停在定义。真正要练的是把它和“市场风险溢价”分开：前者回答哪个变量在动，后者回答这个变量通过什么渠道影响结果。两者经常同时出现，但一个描述状态，一个描述传导；把传导写成状态，就会把相关性误当因果。与“信用利差”的区别则在于层次：前者可以在单个主体上观察，后者要求一组共同规则约束同一批主体。三层混在一起，文章就会看起来什么都说了，实际什么都不能检验。

迁移练习的做法是换三个维度各问一次。换主体：从企业换到家庭，从银行换到基金，风险溢价的分子分母是否仍然成立？换时间：从季度换到年度，从正常期换到危机期，参数是否稳定？换制度：从一套监管换到另一套，市场风险溢价的激励是否方向相反？三次换完，仍能复述同一条机制，才算掌握；一换就崩，说明原来记住的是案例，不是概念。

最后做一次自测：用 100 字解释“风险溢价”，必须包含一个单位、一个时间口径和一个反例；再用 100 字说明“市场风险溢价”在什么条件下会失效。两段都写不出，就回到模块母文和同模块的另一篇主文，先把定义与口径对齐。模块深度不是字数，而是能否在换主体、换时间、换制度后仍给出可复核的判断。

练习

  1. 概念辨别。 国债收益率 4.0%、股票预期回报 9.0%，市场风险溢价是多少？
  2. 计算。 R_f = 4.0%、MRP = 5.0%、β = 1.2，要求回报和资产风险溢价各是多少？
  3. 适用条件。 公司债收益率 6.5%、国债 4.0%，能否把 2.5 个百分点全部称为风险溢价？
参考答案
  1. 9.0%-4.0% = 5.0 个百分点。
  2. 要求回报 4.0% + 1.2 × 5.0% = 10.0%；资产风险溢价 6.0%。
  3. 不能。利差还包含预期违约损失、流动性、税收和条款；应使用同期限、同币种、同税务口径，并扣除预期损失后再比较。

  3. 给“信用利差”找一个规则变化，说明它如何改变样本覆盖。
