概念

现值与现金流贴现

现值把未来现金流按贴现率换算到今天，现金流贴现把多期现金流逐期折现后相加；贴现率、时点和现金流假设共同决定结果。

模块FIN-M08 · 时间价值
层级入门
阅读5 分钟 · 12 节

这篇有一个可以动手操作的演示 ↓

定义

现值（present value, PV）是把未来现金流按适当贴现率换算到今天的价值。现金流贴现（discounted cash flows, DCF）是逐期贴现多笔现金流并求和的估值方法；净现值（NPV）是现值之和减去初始投资。贴现率是对时间与风险的定价，不是公式自动给出的常数。

直觉

一年后的 105 元，在 5% 下今天值 100 元，因为 100 元投资一年正好变成 105 元。若项目今天投入 1,000 元，未来三年收回 300、400、500 元，必须把三笔钱都折回今天，才能与 1,000 元比较。

正式表达

单期与多期现值：

PV = CF_t / (1 + r)^t
PV = Σ_{t=1..n} CF_t / (1 + r)^t

净现值：

NPV = Σ_{t=1..n} CF_t / (1 + r)^t - CF_0（初始投资 CF_0 发生在 t = 0）

普通年金：

PV = C × [1 - (1 + r)^(-n)] / r

其中 CF_t 为第 t 期现金流（货币单位，流入为正、流出为负），r 为每期贴现率（小数），n 为期数，C 为每期等额现金流。CF_0 是初始投资额，按正数成本记入，所以公式写成“减去 CF_0”；若全程按现金流符号约定，t = 0 那一笔应写成 -CF_0 并直接求和，两种写法结果相同。名义现金流配名义利率，实际现金流配实际利率；期数与时点必须一致。本文金额均为教学假设，用于真实项目时须写明币种与单位。 本文以 NPV = Σ现值 − CF_0（CF_0 记正数成本）为主写法，t = 0 直接取负号的写法作为等价形式保留说明；这一约定是本文 2026-11-03 的编辑裁定，是否升为全站统一写法需在发布前逐篇核对后确定。

现值是终值的逆运算：5% 下五年后的 127.63 元现值为 100 元，且除非利率为负，现值小于终值（OpenStax）[1]。

适用条件与边界

  1. 现金流与贴现率同口径。 名义/实际、税前/税后、币种和期数必须匹配。
  2. 公式只有一个 r，即假设各期贴现率不变。 这与货币的时间价值主文（FIN-009）的基础假设相同；利率存在期限结构或随时间调整时，要按期使用不同贴现率，本文算例不覆盖这种情况。
  3. 时点要明确。 期末与期初相差一期；期初年金等于普通年金乘以 (1 + r)。
  4. 贴现率反映风险与机会成本。 用无风险利率贴现风险现金流会高估现值。
  5. 负利率下现值可高于终值。 公式仍成立，但直觉改变。
  6. DCF 对长期假设敏感。 终端价值、增长率和资本支出可能主导结果。
  7. 现金流不确定时，单一情景的 NPV 只是条件性结果。 应做情景或敏感性分析。

普通年金现值可用 PV = C × [1 − (1 + r)^(−n)] / r 一次算出，期初年金需再乘以 (1 + r)；不等额的多期现金流不能套年金公式，只能逐期贴现后求和——教材用 6% 贴现率计算五笔不等额提款的现值[2][3]。

例子与计算

以下均为教学假设。

单笔。 贴现是终值的逆运算：三年后的 1,157.63 元按 r = 5% 贴现，PV = 1,157.63 / 1.05³ ≈ 1,000 元（1.05³ = 1.157625；终值已取整，反算得 1,000.0043，所以用约等号）。同一笔钱按 5% 增长的终值算例见货币的时间价值主文（FIN-009），本文不重复展开，只取贴现这条结论。

多期不等额。 CF_1 = 300、CF_2 = 400、CF_3 = 500，r = 5%：

PV = 300/1.05 + 400/1.05² + 500/1.05³ = 285.71 + 362.81 + 431.92 = 1,080.44 元。

若初始投资 CF_0 = 1,000 元（正数成本），NPV = 1,080.44 - 1,000 = 80.44 元，为正。这里的 1,080.44 是逐项现值先四舍五入到分再相加的结果；若用未取整值求和为 1,080.448，按分四舍五入为 1,080.45，0.01 元差额来自逐项取整。

敏感性。 同一现金流，r = 4% 时 PV = 1,102.78、NPV = 102.78；r = 6% 时 PV = 1,058.83、NPV = 58.83。贴现率上升，现值下降。

年金。 每年末 100 元、三年、5% 的普通年金现值约 272.32 元；这一算例的逐期核对过程见货币的时间价值主文（FIN-009），本文只保留结论，并用它说明期初与期末的差别（见练习 3）。

常见误解

  • 贴现率越高，现值越高。 错，分母变大，现值下降。
  • 现值就是账面价值或市场价格。 错，它是给定现金流与贴现率下的计算结果。
  • 所有现金流都可用同一贴现率。 错，风险、期限、币种和税务不同，应匹配或调整。
  • NPV 为正就一定赚钱。 错，它表示满足给定要求回报率；假设错误或现金流未实现时不成立。

练习

  1. 概念辨别。 其他条件相同，贴现率上升，现值如何变化？A. 上升；B. 下降；C. 不变；D. 无法判断。
  2. 计算。 第 1 年 200 元、第 2 年 300 元，贴现率 5%，现值是多少？
  3. 适用条件。 每年初支付 100 元、共三年、贴现率 5% 的期初年金，其现值比每年末支付的普通年金高还是低？为什么？
参考答案
  1. B。贴现率上升使分母变大，现值下降。
  2. 200/1.05 + 300/1.05² = 190.48 + 272.11 = 462.59 元。
  3. 更高：期初年金等于普通年金乘以 (1 + 0.05)，272.32 × 1.05 ≈ 285.94 元，因为每笔现金流提前一期。
